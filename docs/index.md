# llm-batch-annotate

`llm-batch-annotate` is a Python package and CLI for batch-oriented LLM annotation workflows over tabular datasets. It provides a typed configuration model, batching and grouping helpers, OpenAI Batch execution support, local artifact storage, and resumable orchestration.
